Multi-Class Benchmark Classification Pipeline

📌 Project Overview

This project focuses on building an end-to-end Multi-Class Classification Pipeline using Python and Machine Learning.

The project uses the Iris or Wine dataset to classify data into multiple categories using different machine learning algorithms. It also compares model performance using various evaluation metrics.

🎯 Project Objectives

- Build a supervised machine learning classification model.
- Perform data preprocessing and feature scaling.
- Train Logistic Regression and Decision Tree models.
- Compare the performance of both models.
- Evaluate models using classification metrics.
- Visualize the confusion matrix using a heatmap.

📊 Dataset

This project uses one of the following built-in datasets from Scikit-learn:

- Iris Dataset
- Wine Dataset

The dataset contains multiple features and target classes used for training and testing the classification models.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

⚙️ Project Workflow

1. Import the required Python libraries.
2. Load the Iris or Wine dataset.
3. Perform exploratory data analysis (EDA).
4. Split the dataset into training and testing sets (80:20).
5. Apply StandardScaler for feature normalization.
6. Train Logistic Regression model.
7. Train Decision Tree Classifier model.
8. Predict the test dataset results.
9. Evaluate model performance.
10. Visualize the confusion matrix using a heatmap.

🤖 Machine Learning Algorithms

1. Logistic Regression

A supervised machine learning algorithm used for classification problems.

2. Decision Tree Classifier

A supervised learning algorithm that makes predictions using a tree-like structure of decision rules.

📈 Model Evaluation Metrics

The models are evaluated using:

- Accuracy Score
- Precision Score
- Recall Score
- F1-Score
- Confusion Matrix

These metrics help compare the performance of the classification models.

📉 Visualization

The project includes:

- Exploratory data analysis graphs.
- Confusion matrix heatmap.
- Model performance comparison.
